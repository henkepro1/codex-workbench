# Feedback: List user commands in README

## Rule

When adding or changing commands that a user can run in this workbench, list those user-facing commands in README.md as well as any detailed docs.

## Why

The README is the main human entry point, so commands hidden only in secondary docs are easy to miss.

## When To Apply

Apply during any workbench feature, script, workflow, or documentation change that introduces or changes user-run commands.
